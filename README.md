# Kasukulu

Kasukulu is an interactive learning web app built for Zambian learners across Grades 7, 8–9 Junior Secondary, Grade 10–12 (ECZ School Certificate / GCE), and A-Levels.

## Key Features

- **Personalized ECZ Exam Subjects:** Learners choose the subjects they will write, save them to their study profile, and filter syllabus topics and monthly tests to their exam list.
- **Specialist AI Tutors & Voice Studio:** Guided revision, spoken explanations, and subject mentorship across core Zambian subjects.
- **ECZ Past Papers & Study Pad:** Practice past exam questions with marking scheme guidance, interactive quizzes, and a study/writing pad.
- **Study Planning & Streaks:** Daily study streaks, progress tracking, and after-school/weekend study timetables.
